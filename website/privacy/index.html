Privacy & data use

Mingle is a local development environment with optional account, team, and device features. This page describes the information those features handle and where it goes.

For questions or cloud-data requests, contact mingledevteam@gmail.com.

Local workspace and account sign-in

Your project folders, source files, conversations, and local app data are used by Mingle on your computer. When you choose Google sign-in, Mingle verifies your basic profile and email through Supabase Auth. The app's account session is stored locally encrypted using the operating system's secure storage when available; when secure storage is unavailable, the session is kept in memory instead.

Provider credentials are not stored by Mingle. They remain with the local provider tools and accounts you set up.

Account preferences and team features

If you use cloud account preferences, Mingle stores an allowlisted set of preferences, such as your theme and provider/model defaults, in Supabase under your account.

If you use team and device features, Supabase stores team membership, shared project names and repository URLs, device public keys and presence, and encrypted device-to-device mailbox messages. Mailbox contents are encrypted for the participating devices before they are sent to Supabase.

Work sent to coding providers

When you explicitly send a request to an agent, Mingle passes the work and context needed for that request to the provider you selected. The provider processes that information under its own terms and privacy practices. Mingle does not control how a provider handles information after receiving it.

Project invitation emails

When a project invitation is emailed, the message includes the recipient's email address, project name, repository URL, and a single-use invitation token so the recipient can open the invitation in Mingle. Invitation email is sent through Gmail from mingledevteam@gmail.com.

Logs and this website

Passwords and tokens are not written to Mingle application logs. This public website uses no analytics and loads no third-party assets or scripts.

Sign-out, unlinking, and data requests

Signing out or unlinking a device does not automatically delete your cloud account or all cloud data. Contact mingledevteam@gmail.com for account or cloud-data requests. Mingle does not publish a general retention duration for these records, so no specific deletion timeline is promised here.
